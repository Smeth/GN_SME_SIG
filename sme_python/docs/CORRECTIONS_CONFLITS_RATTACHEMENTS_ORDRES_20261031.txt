de lecture garde le brouillon. La réconciliation en arrière-plan travaille sur

sauvegarde du layout dans le lot, sans assigner l'objet candidat avant commit.

pas de mode de forçage ni de nouvelle tentative métier automatique ajoutés.

Performance et compromis
Deux tests constatent une seule instruction SELECT pour charger chaque sens de
rattachements lorsque les liens existent ; le repli historique sans liens ajoute
la lecture des fonctions observées. Un autre test mesure un seul verrou anticipé
et un seul signal pour un lot imbriqué de deux écritures.
Aucun gain de latence globale revendiqué : pas de benchmark représentatif avant/
après. Calcul JSON/empreinte et contrôles ont un coût. Les écritures de référentiel
s'attendent désormais avant le contrôle, jusqu'au commit : nécessaire aux ensembles
vides et aux intersections. Un import/lot long peut retarder une autre écriture.
Les instantanés comprennent les choix affichés ; une modification d'un choix
non coché ou d'un réglage du layout peut donc imposer de recharger par prudence.
