SME Gendarmerie — version portable (PyInstaller)
==================================================

Contenu du dossier
------------------
- SME_Gendarmerie.exe   : application (interface graphique)
- _internal\            : bibliothèques Python et Qt (ne pas supprimer)
- lancer_SME_Gendarmerie.cmd : raccourci pour lancer l’exe depuis ce dossier

Première utilisation sur un autre PC
--------------------------------------
1. Copiez TOUT le dossier (y compris _internal\) sur la machine cible.
2. Créez un sous-dossier nommé exactement :  data
3. Placez votre base Access dans :  data\smegend.mdb

   OU définissez la variable d’environnement utilisateur :
   SMEDB_PATH = chemin complet vers votre fichier .mdb

   OU lancez l’application puis menu Fichier → « Chemins des fichiers de données… »
   pour enregistrer la base (et optionnellement la maquette Excel), y compris un
   chemin réseau UNC (\\serveur\partage\…). Les chemins sont stockés dans :
   %LOCALAPPDATA%\SME_Gendarmerie\paths.json

4. Optionnel pour la liste des présents (export Excel) :
   - data\liste_present_layout.json  (configuration des sections)
   - data\resultat.xlsx              (maquette Excel), ou variable SME_TEMPLATE_PATH

5. Double-cliquez sur SME_Gendarmerie.exe ou sur lancer_SME_Gendarmerie.cmd

Prérequis Windows
-----------------
- Pilote ODBC Microsoft Access : « Microsoft Access Driver (*.mdb, *.accdb) »
  (généralement présent sur Windows 10/11 ; sinon installer le
   « Microsoft Access Database Engine » Redistributable).

Notes
-----
- Le fichier personnel_audit.jsonl est créé dans data\ lors des modifications (audit).
- En cas de message d’erreur au démarrage, vérifiez le chemin de la base et ODBC.
